# Spinalytics

An explainable spinal measurement analysis and vertebral anomaly-localization platform. Spinalytics compares structured spine measurements with reference distributions, shows which vertebral level and measurement differs and by how much, and highlights the affected levels on an interactive 3D spine.

> **Synthetic data, not a medical device.** This project is developed and evaluated on generated data only. It does not diagnose, and nothing it reports is clinical advice.
